How a loop gets rewritten

  1. Spot the recurring case. The same kind of situation keeps coming back: 3pm at the desk, the TV going on, walking past the kitchen.
  2. Declare the rule. When [cue], I [automatic step], and it gives me [payoff]. Name the closure point, the last moment before the step completes, such as a hand on the cupboard door.
  3. Test one change. Insert one kognem at the closure point. You can add up to two modifiers. Keep it the same for at least five runs.
  4. Classify the result. Over comparable runs, did the old rule still reconstruct (Ψ = 0), is a different rule now running reliably (Ψ ≠ 0), or is there not enough evidence yet (Ψ undefined)?

A kognem doesn't fight the craving or depend on willpower. It changes the order of steps at the point where the automatic loop closes. One good run is a state change. A mutation is a new rule that keeps showing up across runs.
